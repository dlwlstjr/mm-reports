할 일

  • 제품명 정리
    회의 한 번에 AXIS, ExTuner, ExpertSQL(가칭), AIM(AI In MaxGauge), Ask MaxGauge 다섯 개가 같이 나왔어요. 서로 어떤 관계인지 아무도 정리해두지 않았고, 이 상태로는 고객이 무엇이 무엇인지 구분을 못 해요.
    무엇을 하나 다섯 개가 각각 어디까지를 가리키는지 한 장으로 그려요. 그다음 대외에 쓸 이름 후보를 만들어 올려요. (고평석 대표) "엑셈 DB 엔지니어들이 축적한 암묵지가 들어가 있음. 이를 AI화, 솔루션화한 기술로 전달할 수 있도록 제품 명칭과 설명 방식도 함께 고민할 필요"라고 회의에서 직접 말한 사안이에요.
    물어볼 사람 박준연 이사
  • EXPU 브로셔와 로고
    회의록 본문에는 없고 스프레드시트 기술개발 항목에 "브로셔, 로고 디자인 관련 협의 진행"으로 적혀 있어요. 우리 팀 일인데 우리가 모르는 상태로 돌아가는 중일 수 있어요.
    무엇을 하나 누가 어디까지 진행했는지 먼저 확인해요. 같은 기간에 GPU 모니터링 대시보드와 NPU 모니터링 UI 개선도 진행 중이라 제품 화면이 바뀌는 중이에요. 브로셔에 넣을 화면을 확정 시점에 맞춰야 해요.
    물어볼 사람 박용우 이사
  • PWI 웨비나 홍보
    김민서 과장이 주제 선정을 마치고 자료를 만들기 시작했어요. 세션 1은 PostgreSQL Wait Event와 진단 도구, 세션 2는 Memory Lock(Shared Buffer Lock, Wal Buffer Lock), 세션 3은 HWLock(Relation Lock, Row-Level Lock)이에요.
    무엇을 하나 지금 만들고 있는 PostgreSQL 백서와 주제가 그대로 겹쳐요. 백서 따로, 웨비나 따로 알리지 말고 하나로 묶어서 신청과 다운로드를 서로 태워요. 일정을 먼저 맞춰야 해요.
    물어볼 사람 김민서 과장
