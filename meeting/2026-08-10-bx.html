08/10 경영회의 공유

브랜드마케팅팀용. 회의록 본문과 월간경영회의 스프레드시트(고객관리, 기술개발, 지식과 시장, 조직 운영)를 함께 읽고 우리 팀이 가져갈 것만 추렸어요. 대외비 포함

우리 팀 직접 건

  • AXIS 제품 명칭과 설명 방식 정리 (고평석 대표) "엑셈 DB 엔지니어들이 축적한 암묵지가 들어가 있음. 이를 AI화, 솔루션화한 기술로 전달할 수 있도록 제품 명칭과 설명 방식도 함께 고민할 필요"라고 회의에서 직접 요청. 지금 AXIS, ExTuner, ExpertSQL(가칭), AIM(AI In MaxGauge), Ask MaxGauge가 한 회의에서 동시에 거론돼 각각의 범위와 관계를 정리한 자료가 없는 상태. 한 장으로 정리한 뒤 대외 명칭 후보를 제안하는 순서. 문의는 박준연 이사
  • EXPU 브로셔와 로고 디자인 협의 진행 중 회의록 본문에는 없고 스프레드시트 기술개발 시트에 있는 내용. GPU 모니터링 대시보드와 NPU 모니터링 UI 개선도 함께 진행 중. 문의는 박용우 이사
  • PWI 웨비나 준비 착수 김민서 과장이 주제 선정을 마치고 자료 정리 시작. 세션 1은 PostgreSQL Wait Event와 진단 도구, 세션 2는 Memory Lock과 Wait Event(Shared Buffer Lock, Wal Buffer Lock), 세션 3은 HWLock과 Wait Event(Relation Lock, Row-Level Lock). 진행 중인 PostgreSQL 백서와 주제 축이 같아 묶어서 홍보하면 서로 유입을 만들 수 있음
콘텐츠 소재
  • 한국예탁결제원 고객평 "직책자분들 그리고 업무담당자들 모두 인터맥스 화면만 봅니다. 거래가 모두 연결되어 있어 좋아합니다". 인터맥스 매출이 전년 동기 대비 28% 줄어든 국면이라 제품 가치를 고객 목소리로 보여줄 수 있는 문장. 공개 가능 여부와 익명 처리 범위는 확인 필요
  • MaxBot v1.4 업그레이드(8/13) 이기종 DB 지원을 Tibero, DB2, Altibase까지 확대하고 9월에 SQL Server와 Postgres 예정. 이미지 기반 질의응답 추가, InterMax 5.3과 5.4 소스코드 기반 답변으로 화면부터 API, 데이터까지 연결 관계 확인 가능. 사내 AI 활용 사례로도 쓸 수 있는 소재
  • 엑셈원 8월 릴리즈(8/20) GPU 모니터링 개발 완료 후 테스트 중(GPU 기본뷰, 워크로드 기준 오버뷰, 리소스 추이 뷰). AI 챗봇도 8월 릴리즈 포함 목표. AIOps는 개발 중. 일본어 UI 작업도 진행
  • 한전 버추얼그리드 폐쇄망 구축 7/27부터 8/4 사이에 폐쇄망 풀스택 구축이 거의 완료. 패키징 테스트, 폐쇄망 반입, GPU 드라이버와 도커, vLLM 환경 구성, gpt-oss-120b 서빙과 eXemble 구축, VectorDB와 GIS DB 배포까지 진행. 폐쇄망 환경에서 LLM을 실제로 올려본 역량을 보여줄 소재
  • 사내 세미나 주제 통합기술본부 7월 신규입사자 세미나가 엑셈원의 SaaS화를 위한 인프라 아키텍처와 LLM 옵저버빌리티였음. 기술 블로그 저자 발굴 접점이 될 수 있는 주제
  • eXemble GS인증 완료(8/3) 보도자료와 제품 페이지 갱신 대상. 다만 조달 등록과 묶어 발표할지는 아래 주의 항목 확인 후 판단

주의: 사실이지만 지금 대외에 쓰면 안 되는 것

  • AXIS 성능 수치 내부 테스트 21건 중 20건 개선, 개선 배수 중앙값 9.2배(logical reads 감소 기준). 원문에 "고객 검증이나 제품 완료가 아닌 내부 테스트 결과이며 리팩터링, 필드 테스트, 제품화가 남아 있다"고 명시. 대외 콘텐츠에 넣지 않고, 넣게 되면 "내부 테스트 기준"을 반드시 표기

GS인증만 먼저 알리고 조달 등록은 실제 취득 후 별건으로 가는 쪽을 권함
