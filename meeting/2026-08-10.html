3. 기술 개발
  • AXIS 엔진 LLM 없이 SQL과 실행계획에서 병목과 튜닝 후보를 찾고, DB 측정 결과를 다시 읽어 다음 조치를 판단하는 룰 기반 내부 엔진. 내부 테스트 21건 중 20건 개선, 개선 배수 중앙값 9.2배(지표는 logical reads 감소). GPU 제약 환경용 CPU 기반 제공도 검토. 고객 검증도 제품 완료도 아닌 내부 테스트 단계이며 리팩터링과 필드 테스트, 제품화가 남음. (박준연 이사) 상용과 오픈 LLM 그대로는 한계, 파인튜닝도 미흡해 LLM 역할을 로직으로 분리하며 룰 엔진으로 발전. (고평석 대표) 엑셈 DB 엔지니어 암묵지가 들어간 기술이므로 제품 명칭과 설명 방식도 함께 고민 필요. (이영수 부사장) 고객 시스템과 데이터 맥락 반영이 중요, LLM 모듈 결합도 검토
  • ExpertSQL(가칭) DBA가 SQL 성능을 분석하고 조치를 찾도록 지원하는 전문가용 통합 도구 구상. (이영수 부사장) DB 운영자를 넘어 일반 사용자까지 접근 범위 확장 필요. (박준연 이사) AIM(AI In MaxGauge), RCA, Ask MaxGauge와 화면 기반 Top-down 분석 연결 검토
  • ExTuner UI와 UX, 3건 병렬 튜닝 개발 중. 현재 PoC 즉시 반영은 어려워 수협 또는 다음 단계부터 적용 예상. (이영수 부사장) QueryMedic 경험이 많은 KB라이프에서 비교 BMT와 PoC로 성능과 차별점 객관 확인 필요, 성능 미달 시 판매 추진을 보수적으로 판단할 기준 필요
  • 차세대 MaxGauge와 Exadata 8월 목표는 개발 완료가 아니라 가능한 과업의 기술 기획 80%. 9월 분기 점검 전까지 과장급 인력 내부 프로젝트 집중. Exadata DMA 검증은 개발자 현장 검증 환경이 필요해 약 2~3주 접근과 보안, 결과 반출 조건 검토. 온사이트가 부담이면 클라우드 검증 대안(OCI 크레딧, 클라우드 임대)
  • eXemble 8월 3일 GS인증 완료. 조달 등록 전제는 실적증명 3건과 8월 29일 부정당 제재 종료. AI 제품 소프트웨어 확인 신청은 서류 준비 완료 상태이나 신청 페이지 오류로 미접수. 확인서 취득 시 실적증명 면제 가능성. (류길현 전무) 시스템 사업과 함께 적용하며 완성도를 높여야 하므로 당분간 현장 사업을 통한 고도화 필요. (고평석 대표) TTA 담당자 확인과 처리 기간 단축 협의 요청
  • K8s 인력과 SaaS 구조 K8s 엔지니어 1~2명 채용으로 운영 경험을 쌓아 제품과 향후 SaaS에 활용하는 방안 제안. (이영수 부사장) 별도 사업화는 어렵지만 경험 많은 인력 확보로 제품에 반영하는 것은 의미 있음. SaaS 전환을 위해 테넌트와 셀 분리 구조 테스트 중
  • 하반기 AI 사업 후보 5건 한전 SCM, NL2SQL, MDMS, AI 플랫폼 4건과 KDN AX 실증 1건. 주관사 논의가 남고 일정과 규모에 따라 투입 인력 이슈 가능. (이영수 부사장) 직접 주도 사업은 사업별 PM과 PL, 투입 인력 계획 구체화 필요
