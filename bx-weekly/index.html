6월 25일(목) 진행된 「2026 AI 활용 MS SQL Server Tuning 기술 세미나」 결과 공유드립니다.
2026년도 두 번째 기술 세미나로, 발표를 맡아주신 DB성능마스터팀 김성식 이사님·이병찬 컨설턴트님과 고객 초청에 힘써주신 영업대표님들께 감사드립니다.
이번 세미나는 ‘AI 활용’을 전면에 내세운 첫 세미나로, 신간 『GitHub Copilot Chat과 함께하는 SQL 튜닝 가이드』와 연계해 차별화된 구성으로 진행되었으며, 만족도 조사 응답자 전원이 7점 이상 (평균 8.47점) 으로 응답하며 세미나 콘텐츠에 대한 만족도가 높았습니다. 또한 참석자가 인식하는 주요 IT 운영 과제와 AI 기능 수요가 exemONE·AI Tuner 기능과 높은 연계성을 보이는 점을 확인할 수 있었습니다.
본 메일에는 사후 만족도 조사 결과를 기준으로 후속 컨택 대상 고객을 정리한 결과보고 파일을 첨부합니다.
※ 4번 내용으로 솔루션 관련 요청 고객에 대한 영업 후속 컨택 진행 현황 공유 요청 확인 부탁드립니다.
1. 주요 요약
-사전 신청자 수: 63명 (참석 확정 45명 / 미응답 13명 / 참석 불가 5명)
-실제 참석자 수: 45명 (참석 불가 5명 제외 58명 기준, 참석률 약 78%)
-만족도 조사 응답 수: 34명 (응답률 75.6%)
-평균 만족도: 8.47점 / 10점 만점
-NPS 지수: 44.1 (3월 세미나 NPS 지수 43.5 → 6월 44.1로 상승) 
   → 응답자 전원이 7점 이상(만족) 부여 및 44.1%가 적극 추천(9~10점), B2B 평균 20~30 대비 높은 수치
   ※ NPS: 추천 의향(0~10점)으로 고객 충성도를 보는 지표
-영업 후속 컨택 요청 고객: 14명
2. 실제 참석자 분류 (45명)
-산업군: IT/소프트웨어 53.3%(24명) > 금융 24.4%(11명) > 제조 6.7%(3명) > 공공기관 4.4% (2명) > 외 기타
-주요 업무 영역(복수): DBA/DB 운영 88.9%(40명) > IT 인프라 운영 33.3%(15명) > 시스템·백엔드 개발 13.3%(6명)
-SQL 튜닝 경험: 실무 경험 있음 40.0%(18명) = 기본 개념 보유 40.0%(18명) > 튜닝 주담당 13.3%(6명) > 처음 배우는 단계 6.7%(3명)
→ 참석자의 90%가  DBA/DB 운영 직무, 80%가 실무 경험·기본 개념 보유 단계로 '실전 사례 기반 튜닝 노하우' 니즈가 높은 핵심 운영층 중심
3. 만족도 설문 결과 요약
첨부된 엑셀 파일 내 ‘설문 결과’ 탭에서 전체 설문결과 요약값 확인 가능합니다. 메일 본문에는 설문 주요 내용 요약하여 공유드립니다.
3-1. 응답자 프로필 (34명)
-직책: 시니어 실무자 55.9%(19명) > 주니어 실무자 38.2%(13명) > 관리자 5.9%(2명)
-산업군: IT/소프트웨어 52.9%(18명) > 금융 23.5%(8명) > 제조 5.9%(2명) > 공공기관 5.9%(2명) > 외 기타
-주요 업무 영역(복수): DBA/DB 운영 85.3%(29명) > IT 인프라 운영 35.3%(12명) > 시스템·백엔드 개발 14.7%(5명)
→ 실제 참석자(45명)와 거의 동일하게 DBA/DB 운영·실무 경험층이 만족도 조사에 참여해, 설문 결과가 참석자 전체를 대표함
-SQL 튜닝 경험: 실무 경험 있음 44.1%(15명) > 기본 개념 보유 41.2%(14명) > 튜닝 주담당 8.8%(3명) > 처음 배우는 단계 5.9%(2명)

→ MS SQL 주제임에도 Oracle DB 주력 운영사가 최다 참석
3-2. IT 운영 환경 및 과제
-운영 환경: 온프레미스 중심 52.9%(18명) > 하이브리드 38.2%(13명)

→ 상위 과제 모두 exemONE 핵심 기능과 직접 연계
-성능 이슈 원인 파악 평균 소요 시간(MTTD): 30분~1시간 50.0%(17명) > 1시간~3시간·30분 이내 각 20.6%(7명) > 3시간 이상 8.8%(3명)
→ 전체의 79.4%가 원인 파악에 30분 이상 소요, exemONE·AI Tuner 도입 효과 메시지로 활용 가능
3-3. AI 기능 수요
-AI 자동 튜닝 활용 의향: 참고 수준 활용 61.8%(21명) > 적극 활용 38.2%(13명) 
-기대 AI 기능(복수): SQL 성능 자동 분석·튜닝 가이드 82.4%(28명) > AI 이상탐지·장애 자동 알림 47.1%(16명) > 폐쇄망 지원 사내 지식 AI 비서 41.2%(14명) > 근본 원인 분석 자동화(RCA) 38.2%(13명)
→ SQL 자동 튜닝 가이드 수요 82%로 최다 (AI Tuner 직접 수요)/  폐쇄망 AI 기능 수요 41% (금융·공공 보안망 고객 니즈)
